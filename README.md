# کالای شاد

وب‌سایت فارسی فروش و اجاره ملزومات جشن؛ نسخه نمایشی تعاملی با رنگ کرم و زیتونی، تقویم محلی اجاره و پیش‌نمایش چیدمان.

## انتشار در GitHub Pages
۱. محتوای این پوشه را در ریشه یک مخزن GitHub با شاخه main قرار دهید؛ پوشه مخفی .github هم باید منتقل شود.
۲. در Settings → Pages، گزینه Source را روی GitHub Actions بگذارید.
۳. از Actions، گردش‌کار Publish Kalaye Shad را اجرا کنید یا یک تغییر در main ثبت کنید.
۴. لینک عمومی پس از موفق‌شدن انتشار در Settings → Pages و خروجی گردش‌کار نمایش داده می‌شود.

این روش مطابق راهنمای رسمی است:
https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## اجرا
index.html را باز کنید. نصب یا ساخت لازم نیست. تصویرهای اختصاصی در assets هستند و بعضی تصاویر و فونت از اینترنت دریافت می‌شوند.

## حدود نسخه
قیمت‌ها، تعدادها، اجاره‌ها، درخواست‌ها و چیدمان‌های ذخیره‌شده فقط در مرورگر هر بازدیدکننده نگهداری می‌شوند. این بسته هیچ داده ذخیره‌شده مرورگر، حساب، رمز، کلید یا درخواست مشتری را شامل نمی‌شود. مخزن فقط فایل‌های سایت را دارد.
مدیریت آزمایشی، پنل امن نیست؛ موجودی بین مشتری‌ها مشترک نیست. رزرو قطعی، پرداخت، ورود امن و ارسال درخواست به مجموعه به سرور نیاز دارند. تصاویر نمونه‌کار تأییدشده نیستند و برای نمایش سبک استفاده شده‌اند.
